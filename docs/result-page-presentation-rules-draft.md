# 結果頁呈現規則草案

建立日期：2026-05-29

## 這次要解決的問題

目前結果頁會把「只有一個面向約 60 分、其他面向都偏高」的狀態顯示成：

> 目前有些輕度拉扯，可先補強最低分面向

這容易讓使用者覺得被誤判。60 分雖然是相對低分，但不一定代表風險矛盾；如果其他面向落在 80 到 90 分以上，整體更像是「狀態穩定，但有一個觀察面向」，而不是「多方拉扯」。

## Agent 討論摘要

### scoring_logic_agent

判斷：

- 現有邏輯過度依賴「是否全部高於 65」與「最低分」。
- `mixed_awareness` 目前像 fallback，沒有明確門檻，所以會吃掉太多普通案例。
- 結果分類需要同時看「絕對分數」與「相對落差」。

建議：

- 先判斷是否存在絕對低分，再判斷相對落差。
- 60 到 64 分應該是「觀察」，不是「矛盾」。
- 只有出現低於 55 或兩個以上低於 60 的面向，才適合使用「拉扯」或「矛盾」語氣。

### investment_risk_tolerance_agent

定位：

- 投資教育與風險承受度專家。
- 只檢查「風險承受度呈現是否合理」，不提供投資標的、資產配置或買賣建議。

判斷：

- 投資風險承受度通常要同時看「願意承受」與「實際能承受」，也要看資金用途、時間範圍、流動性需求與生活財務狀況。
- 單一面向 60 分，不足以推論使用者有明顯風險矛盾。它比較像一個需要進一步了解的訊號。
- 若財務安全、生活結構、投資理解與市場波動反應都高，只有金錢焦慮與動機 60，投資風險承受度專家的判讀會是「整體承受能力不差，但投資動機/情緒觸發值得觀察」。
- 結果頁不能把「相對最低」直接等同於「不適合投資」或「承受力不足」。

建議：

- 結果頁應把「風險能力」與「風險感受/動機」分開說。
- 低於 55 才進入較明確的承受落差提醒；60-64 應該保留為觀察區。
- 若出現高分能力面向搭配中間分數的焦慮面向，應呈現為「整體有支撐，但容易被特定情境牽動」，而不是「多方拉扯」。
- 若未來要更接近正式投資風險屬性評估，還需要更多題目與明確權重；目前這份工具應維持「投資風險覺察」而不是「風險屬性評等」。

### Taiwan user readability agent

判斷：

- 台灣使用者看到「矛盾」「拉扯」「補強最低分」會覺得比較像診斷或考試。
- 若使用者明明大多數面向高分，卻被說「多方拉扯」，信任感會下降。
- 結果頁應該先肯定整體狀態，再指出觀察面向。

建議：

- 用「需要觀察」取代「有問題」。
- 用「相對需要留意」取代「最低分」。
- 避免把 60 分講得像危險訊號。

### risk_guardian

判斷：

- 結果不應像投資建議、心理診斷或財務診斷。
- 「你需要補強」比「可以先整理」更容易越界。
- 如果分數仍在中間以上，過度警示會形成不必要焦慮。

建議：

- 風險矛盾只用在明顯落差或明顯低分。
- 中間分數以「整理、釐清、觀察」呈現。
- 下一步繼續導向好理家在服務，不給配置或投資行動。

### service_fit_agent

判斷：

- 好理家在可以承接「家庭財務與生活脈絡整理」，不應承接「投資配置答案」。
- 結果頁應該幫使用者知道要帶著什麼問題回到服務，而不是告訴他該怎麼投資。

建議：

- 每種結果都輸出一個「可以帶回好理家在整理的問題」。
- 對穩定但有觀察面向的案例，導向「問問 AI / 財務健檢」比導向「線上諮詢」更自然。

## 結果頁建議改成三層

### 第一層：整體承受狀態

回答「你目前整體看起來如何？」

這一層應優先看絕對分數。相對最低分只能作為第二層的觀察入口，不能直接決定主標題。

建議分類：

| 條件 | 分類 | 語氣 |
| --- | --- | --- |
| 所有面向 >= 75 | 整體穩定 | 肯定、提醒定期回看 |
| 平均 >= 75，且最低面向 >= 60 | 整體穩定，有一個觀察面向 | 肯定為主，指出相對低分 |
| 平均 >= 65，且最低面向 >= 60 | 大致穩定，可先觀察相對低分 | 中性、整理 |
| 有 1 個面向 55-59 | 有一個面向需要留意 | 不說矛盾，說留意 |
| 有 2 個以上面向 55-59 | 有幾個面向出現拉扯 | 輕度提醒 |
| 任一面向 < 55 | 進入風險矛盾判斷 | 明確提醒 |
| 任一面向 < 45 | 明顯承受落差 | 高提醒 |

### 第二層：主要觀察面向

回答「哪裡相對值得先看？」

規則：

- 如果最低分 >= 60，稱為「主要觀察面向」。
- 如果最低分 55-59，稱為「需要留意的面向」。
- 如果最低分 < 55，稱為「主要承受落差」。
- 不建議在分數 >= 60 時使用「補強」「矛盾」「風險」作為主標籤。

### 第三層：是否存在明顯風險矛盾

回答「兩個面向是否真的互相打架？」

建議只有以下情況稱為矛盾：

- 心理穩定或市場波動反應高，但財務安全感低於 55。
- 情緒/焦慮面向低於 55，且投資動機也低於 55。
- 投資理解低於 55，但心理穩定度高於 65，代表「敢承受但可能不知道自己承受什麼」。
- 生活安全結構低於 55，且金錢焦慮低於 60，代表生活壓力可能推動投資。

投資專家視角補充：

- 「矛盾」應該描述承受能力、承受意願、投資理解、資金用途或生活流動性之間的衝突。
- 如果只是某一面向比其他面向低，但仍在 60 分以上，應稱為「觀察面向」，不宜稱為矛盾。
- 結果頁應避免讓使用者以為這是一份正式金融機構風險屬性評估。

## 建議分數門檻

| 分數 | 名稱 | 結果頁語氣 |
| --- | --- | --- |
| 80-100 | 穩定 | 目前相對穩定，可定期回看 |
| 65-79 | 可接受 | 整體可支撐，但仍可觀察 |
| 60-64 | 觀察 | 不是危險，但值得看見 |
| 55-59 | 留意 | 可能開始影響承受力 |
| 45-54 | 承受落差 | 需要較明確整理 |
| 0-44 | 明顯風險 | 需要先停下來釐清生活與壓力 |

## 建議結果分類

### A. 整體穩定型

條件：

- 所有面向 >= 75。

標題：

> 目前整體承受狀態相對穩定

摘要：

> 你的財務安全、生活結構、投資理解與情緒反應目前大致能互相支撐，沒有看到明顯的承受落差。

### B. 穩定但有觀察面向

條件：

- 平均 >= 75。
- 最低分 >= 60。
- 至少有一個面向比最高分低 20 分以上。

標題：

> 整體狀態穩定，但有一個面向值得觀察

摘要：

> 你的多數面向都相對穩定，目前沒有看到明顯風險矛盾。不過「{最低面向}」相對低一些，可以當成接下來整理問題的入口。

適用於這次截圖：

- 財務安全感 80%
- 市場波動反應 93%
- 投資理解程度 87%
- 生活安全結構 93%
- 金錢焦慮與動機 60%

建議呈現：

> 你的整體承受狀態相對穩定，但「金錢焦慮與動機」是目前較值得觀察的面向。

投資專家補充文案：

> 從風險承受度角度看，你的財務與生活支撐並不弱；比較需要留意的是，特定行情或比較感是否會影響你的投資節奏。

### C. 大致穩定，可先整理相對低分

條件：

- 平均 >= 65。
- 最低分 >= 60。
- 未達 B。

標題：

> 大致穩定，可先看相對低分面向

摘要：

> 目前沒有看到明顯承受落差；如果要更了解自己，可以先從分數相對低的面向整理一個具體問題。

### D. 單一面向需要留意

條件：

- 只有一個面向落在 55-59。
- 其他面向 >= 60。

標題：

> 有一個面向需要多留意

摘要：

> 整體沒有出現多方拉扯，但「{最低面向}」可能已經開始影響你的承受感，可以先把它整理清楚。

### E. 多個面向有輕度拉扯

條件：

- 兩個以上面向落在 55-59。
- 沒有低於 55 的面向。

標題：

> 幾個面向有輕度拉扯

摘要：

> 目前不是單一問題，而是幾個面向都出現一點壓力；可以先看哪一個最影響你的生活與判斷。

### F. 明顯風險矛盾

條件：

- 命中特定矛盾規則。
- 或任一面向 < 55。

標題依矛盾類型決定，例如：

- 心理敢承受，但財務緩衝偏薄
- 容易被行情與比較感推著走
- 心態相對穩，但理解可能還不夠完整
- 生活壓力可能正在放大投資壓力

## 結果頁版面建議

建議主卡片順序：

1. 整體狀態一句話
2. 主要觀察面向
3. 是否有明顯風險矛盾
4. 為什麼值得看
5. 可以帶回好理家在整理的問題

範例：

```text
整體狀態：相對穩定

主要觀察面向：金錢焦慮與動機 60%

這不是明顯風險矛盾，但它是目前相對值得觀察的地方。
你可以先想想：我投資時，是在照自己的節奏，還是在被「怕錯過」或「想證明自己」推著走？
```

## 文案語氣規則

建議使用：

- 目前看起來
- 相對穩定
- 值得觀察
- 可以先整理
- 帶著這個問題回到好理家在

避免使用：

- 你有問題
- 你需要補強
- 風險很高
- 你不適合
- 你應該調整投資比例
- 你需要諮商

## 新增測試案例建議

### scoring boundary tests

必測案例：

1. `80, 93, 87, 93, 60`  
   預期：穩定但有觀察面向，不是 mixed awareness。

2. `75, 75, 75, 75, 75`  
   預期：整體穩定。

3. `65, 65, 65, 65, 65`  
   預期：大致穩定，不是矛盾。

4. `90, 90, 90, 90, 55`  
   預期：單一面向需要留意。

5. `90, 90, 90, 56, 56`  
   預期：幾個面向有輕度拉扯。

6. `80, 90, 90, 90, 54`  
   預期：進入明確風險提醒或矛盾判斷。

7. `50, 80, 80, 80, 80`  
   預期：心理敢承受，但財務緩衝偏薄。

8. `80, 50, 80, 80, 50`  
   預期：容易被行情與比較感推著走。

## 需要 Kevin 判斷的地方

1. 60-64 分要不要稱為「觀察」，還是「可接受但相對低」？
2. 55-59 分要不要稱為「留意」，還是「輕度拉扯」？
3. 只有一個 55-59 時，要不要避免「拉扯」這個詞？
4. 「穩定但有觀察面向」是否符合好理家在想給使用者的感覺？
5. 結果頁是否要明確顯示「這不是明顯風險矛盾」？

## 初步建議

建議先採用：

- 60-64：觀察面向
- 55-59：需要留意
- 低於 55：才進入風險矛盾或承受落差
- mixed awareness 不再作為泛用 fallback
- 新增「穩定但有觀察面向」分類

這樣可以避免高分使用者因為一個 60 分被誤判，也能保留測驗對低分與矛盾狀態的提醒能力。
